# Prasad Sable — AI Engineer Portfolio

A modern, high-performance developer portfolio built with **Next.js 16 (Turbopack)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

Showcases Generative AI applications, RAG architectures, Agentic AI systems, Computer Vision implementations, interactive case studies, and integrated resume downloads.

## 🚀 Featured Projects
- **PagePilot AI:** RAG-Powered Browser Assistant & AI Automation Agent (Chrome Extension Manifest V3, LangChain, FAISS, FastAPI, Ollama).
- **ByteCraft AI:** Adaptive Micro-Learning Platform with Generative Curriculum powered by Gemini 2.0 Flash.
- **Driver Monitoring AI:** Road Safety Edge Computer Vision System (MediaPipe, OpenCV, Raspberry Pi, WebSockets).

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router & Turbopack)
- **UI & Styling:** React 19, Tailwind CSS v4, Lucide Icons
- **Language:** TypeScript
- **Deployment:** Vercel

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

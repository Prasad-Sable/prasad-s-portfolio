## PagePilot AI

### RAG-Powered Browser Assistant & AI Automation Agent

### Overview

PagePilot AI is a Chrome extension designed to make webpage
interaction more intelligent through Large Language Models and
Retrieval-Augmented Generation.

### Problem Statement

Users often need to manually read, search, and extract information from
lengthy webpages. Performing browser operations also requires repetitive
manual interaction.

### Solution

Developed an AI-powered browser assistant that processes webpage content
for context-aware question answering and translates natural-language
instructions into browser actions.

### Architecture / Workflow

1.  Webpage content extraction.
2.  HTML parsing and text processing.
3.  Text chunking.
4.  Hugging Face embedding generation.
5.  FAISS vector indexing.
6.  Context retrieval.
7.  LLM-based response generation.
8.  Browser action execution.

### Key Features

-   Context-aware question answering.
-   Webpage summarization.
-   Information extraction.
-   Semantic retrieval.
-   Browser automation.
-   OpenAI and Ollama integration.

### Technology Stack

Python · LangChain · FAISS · FastAPI · Hugging Face · OpenAI · Ollama ·
JavaScript · Chrome Extension Manifest V3.

### Contribution

-   RAG pipeline implementation.
-   Document processing and indexing.
-   LLM integration.
-   Browser action agent.
-   Frontend-backend communication.
